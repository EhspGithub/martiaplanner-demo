# 🎓 MartiaPlanner — سامانه هوشمند مدیریت مطالعه و برنامه‌ریزی روزانه دانش‌آموز

**MartiaPlanner** یک اپلیکیشن چندسکویی (Cross-Platform) مهندسی‌شده برای دانش‌آموزان مقطع متوسطه اول (پایه‌های هفتم، هشتم و نهم) است که با معماری **Tauri 2 + React 19 + TypeScript + SQLite** توسعه یافته است. این نرم‌افزار به دانش‌آموز کمک می‌کند برنامه روزانه و فردای خود را بر اساس اولویت‌های استاندارد (`A1` تا `C3`) تنظیم کند، عملکرد واقعی خود را پس از مطالعه ثبت نماید و انحراف زمانی بین «پیش‌بینی» و «عملکرد واقعی» را به‌صورت دقیق تحلیل کند.

---

## ✨ ویژگی‌ها و ماژول‌های کلیدی

1. **ماژول برنامه‌ریزی هوشمند (برنامه امروز، برنامه فردا و نمای هفتگی شمسی):**
   - فرم پویا و هوشمند: در صورت انتخاب فعالیت از نوع **«درس»**، فیلدهای *نام درس*، *فصل / درس* و *نوع فعالیت درسی (تکلیف، امتحان، پس‌خوانی، بدون فعالیت)* نمایش داده می‌شوند و برای فعالیت‌های غیردرسی (*استراحت، استفاده از گوشی، تلویزیون، بازی و...*) فرم به‌صورت خودکار ساده‌سازی می‌شود.
   - سیستم اولویت‌بندی ۹ سطحی استاندارد (`A1 ← A2 ← A3 ← B1 ← B2 ← B3 ← C1 ← C2 ← C3`).
   - تفکیک کامل اطلاعات روزها بر اساس تقویم شمسی (جلالی) همراه با نمای کارت‌های روزانه و برنامه هفتگی (شنبه تا جمعه).

2. **ماژول ثبت عملکرد واقعی و مقایسه با پیش‌بینی:**
   - ثبت مدت زمان واقعی مطالعه (دقیقه)، تعداد تمرین یا تست حل‌شده (با پشتیبانی از عدد صفر)، کیفیت یادگیری (*عالی، خوب، متوسط، ضعیف*) و وضعیت تکمیل (*تکمیل‌شده* یا *ناقص / نیمه‌تمام*).
   - **قفل هوشمند زمان پیش‌بینی‌شده:** پس از ثبت عملکرد واقعی، زمان پیش‌بینی‌شده اولیه در دیتابیس قفل می‌شود (`initial_predicted_minutes`) و سوابق تغییرات در جدول `plan_history_audit` نگهداری می‌گردد تا تحلیل‌های مقایسه‌ای هرگز دستخوش خطا نشوند.

3. **ماژول تعریف درس‌ها و ساختار آموزشی پویا:**
   - تعریف و ویرایش کتاب‌های درسی پایه هفتم، هشتم و نهم به همراه واحد ساختاری هر کتاب (*درس، فصل، پودمان*).
   - مدیریت، افزودن، ویرایش، حذف و تغییر ترتیب فصل‌ها یا درس‌های هر کتاب به‌صورت کاملاً پویا در دیتابیس.
   - **حفاظت از سوابق تاریخی (Snapshot Protection):** تغییر یا حذف یک درس یا عنوان فعالیت در آینده، اطلاعات برنامه‌های ثبت‌شده در روزهای گذشته را تخریب نمی‌کند.

4. **ماژول داشبورد و تحلیل عملکرد (۱۰ شاخص کلیدی):**
   - محاسبه لحظه‌ای از روی دیتابیس واقعی در سه بازه **امروز**، **این هفته** و **این ماه شمسی**:
     1. مجموع زمان پیش‌بینی‌شده مطالعه
     2. مجموع زمان واقعی مطالعه
     3. اختلاف و انحراف زمان پیش‌بینی‌شده و واقعی
     4. مجموع تمرین‌ها و تست‌های حل‌شده
     5. میانگین کیفیت یادگیری
     6. تعداد کل فعالیت‌های برنامه‌ریزی‌شده
     7. تعداد فعالیت‌های تکمیل‌شده
     8. تعداد فعالیت‌های ناقص یا انجام‌نشده
     9. درصد پایبندی به برنامه
     10. میزان زمان صرف‌شده برای فعالیت‌های غیردرسی

5. **ماژول تنظیمات، پشتیبان‌گیری و اتصال مستقیم به GitHub:**
   - مدیریت پویا برای «عنوان فعالیت‌ها»، «انواع فعالیت درسی» و «سطوح اولویت».
   - خروجی و بازیابی کامل دیتابیس (JSON Backup / Restore).
   - پنل اختصاصی اتصال و پوش (Push) مستقیم پروژه به مخزن `MartiaPlanner` در گیت‌هاب.

## 🏗️ معماری فنی و ساختار دیتابیس (SQLite)

پروژه از یک پایگاه داده رابطه‌ای **SQLite** (در حالت سرور/وب با `better-sqlite3` در مسیر `data/martia_planner.sqlite` و در حالت دسکتاپ/اندروید با `tauri-plugin-sql` در مسیر `sqlite:martia_planner.db`) استفاده می‌کند:

- `activity_categories`: عناوین فعالیت‌های درسی و غیردرسی قابل تنظیم
- `study_activity_types`: انواع فعالیت‌های درسی (تکلیف، امتحان، پس‌خوانی، بدون فعالیت)
- `priority_levels`: ماتریس اولویت‌بندی `A1` تا `C3`
- `subjects` و `subject_units`: ساختار درختی کتاب‌های درسی و فصل/درس‌های هر کتاب
- `daily_plans`: برنامه‌های ثبت‌شده به همراه Snapshot نام درس و فصل و زمان پیش‌بینی‌شده اولیه
- `performance_logs`: گزارش عملکرد واقعی هر فعالیت (ارتباط ۱ به ۱ با برنامه)
- `plan_history_audit`: جدول ممیزی تغییرات زمان پیش‌بینی‌شده جهت حفظ صحت تحلیل‌ها

## 🚀 راهنمای نصب و اجرا

### ۱. اجرا در محیط توسعه (Full-Stack Web + SQLite)

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور Express + SQLite + Vite روی پورت 3000
npm run dev
```

### ۲. ساخت خروجی ویندوز (Windows `.exe` / `.msi` با Tauri 2)

پیش‌نیاز: نصب بودن [Rust](https://rustup.rs/) و Microsoft C++ Build Tools روی ویندوز.

```bash
# اجرای محیط توسعه دسکتاپ Tauri
npm run tauri:dev

# ساخت فایل نصبی نهایی ویندوز
npm run tauri:build
```

### ۳. ساخت خروجی اندروید (Android `.apk` / `.aab` با Tauri 2)

پیش‌نیاز: نصب بودن Android Studio، Android SDK و NDK.

```bash
# مقداردهی اولیه پروژه اندروید
npm run tauri:android:init

# ساخت خروجی اندروید
npm run tauri:android:build
```

## 🔗 راهنمای کامل اتصال و Push به مخزن `MartiaPlanner` در GitHub

اگر پروژه را روی سیستم خود دانلود کرده‌اید، با اجرای دستورات زیر در ترمینال (پوشه اصلی پروژه) می‌توانید آن را به مخزن `MartiaPlanner` در گیت‌هاب متصل و پوش کنید:

```bash
# ۱. مقداردهی اولیه مخزن گیت در پوشه پروژه
git init

# ۲. تغییر نام شاخه اصلی به main
git branch -M main

# ۳. افزودن تمام فایل‌های پروژه (فایل .gitignore از پوش شدن node_modules و فایل‌های موقت جلوگیری می‌کند)
git add .

# ۴. ثبت اولین کامیت مستند
git commit -m "feat: initial commit of MartiaPlanner (Tauri 2 + React + SQLite)"

# ۵. اتصال به مخزن ریموت MartiaPlanner در گیت‌هاب (نام کاربری گیت‌هاب خود را جایگزین YOUR_USERNAME کنید)
git remote add origin https://github.com/YOUR_USERNAME/MartiaPlanner.git

# ۶. ارسال (Push) کدها به شاخه main در گیت‌هاب
git push -u origin main
```

> **نکته:** همچنین در داخل خود برنامه، در منوی **«تنظیمات و گیت‌هاب»** می‌توانید بدون نیاز به ترمینال و تنها با وارد کردن توکن گیت‌هاب یا اتصال OAuth، کل سورس‌کد را مستقیماً به مخزن `MartiaPlanner` پوش کنید.
